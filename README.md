A cozy shared-room game for long-distance couples: two players hang out in the same 3D room in real time, decorate it together, and leave things for each other while apart. Built on a custom C++ mini-engine, with a Go backend and a C# item editor.

## Roadmap

- [x] **Phase 0**: Project setup (CMake, unit tests, CI on Windows + Linux, clang-format)
- [ ] **Phase 1**: 3D math library (vectors, matrices, quaternions, ray casting, AABB)
- [ ] **Phase 2**: Engine core (window, 3D rendering, camera, input, ECS)
- [ ] **Phase 3**: Gameplay (avatars, grid-based furniture placement, interactions)
- [ ] **Phase 4**: Debug tooling and profiling
- [ ] **Phase 5**: Networking + Go backend (pairing, live sync, persistent room state)
- [ ] **Phase 6**: C# item editor
- [ ] **Phase 7**: Polish (lighting, custom OpenGL renderer)
