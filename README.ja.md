遠距離恋愛中のカップル向けの「部屋共有」ゲームです。2人のプレイヤーが同じ3Dの部屋でリアルタイムに過ごし、一緒に模様替えをしたり、会えない時間に相手へ何かを残したりできます。自作のC++ミニエンジン上に構築し、バックエンドはGo、アイテムエディタはC#で開発しています。

## ロードマップ

- [x] **フェーズ0**:プロジェクト構築(CMake、ユニットテスト、Windows/LinuxでのCI、clang-format)
- [ ] **フェーズ1**:3D数学ライブラリ(ベクトル、行列、クォータニオン、レイキャスト、AABB)
- [ ] **フェーズ2**:エンジンのコア(ウィンドウ、3D描画、カメラ、入力、ECS)
- [ ] **フェーズ3**:ゲームプレイ(アバター、グリッド式の家具配置、インタラクション)
- [ ] **フェーズ4**:デバッグツールとプロファイリング
- [ ] **フェーズ5**:ネットワーク+Goバックエンド(ペアリング、リアルタイム同期、部屋データの永続化)
- [ ] **フェーズ6**:C#製アイテムエディタ
- [ ] **フェーズ7**:仕上げ(ライティング、自作OpenGLレンダラー)
